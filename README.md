# Recall Product Showcase

A looping, animated preview of Recall — Your Second Brain for IT, built as a single self-contained HTML/CSS/JS showcase page (no build step, no dependencies besides Google Fonts).

Live: https://deadwayz.github.io/recall-showcase/

![recall showcase preview](recall.gif)

Recall was built to solve a common IT knowledge problem: scattered information, repeated troubleshooting, and time wasted searching for solutions that already exist.

The platform provides a centralized knowledge hub where IT professionals can capture, organize, secure, and instantly retrieve critical information such as troubleshooting fixes, email templates, technical notes, procedures, and internal documentation.

What it does
- Personal IT knowledge management and searchable documentation
- Store troubleshooting fixes, technical solutions, and reusable references
- Organize email templates, notes, procedures, and internal knowledge
- Fast retrieval of saved information through intelligent search
- Secure individual knowledge entries with item-level protection controls
- Reduce repeated problem-solving by making previous solutions instantly accessible
- Lightweight and fast interface designed for everyday IT workflows

Built with
- TypeScript
- Cloudflare Workers
- Cloudflare D1 Database
- CSS
- HTML
- AI-powered knowledge retrieval workflows
- Secure item-level access controls
- Modern responsive web application architecture
